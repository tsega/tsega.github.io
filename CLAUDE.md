## Claude Code

- Use the `gh` CLI for GitHub issues and pull requests in `tsega/tsega.github.io`.

- When porting a section, read the matching part of `design/portfolio/index.dc.html` (markup, inline styles and the data in its `DCLogic` script) before writing the component.
